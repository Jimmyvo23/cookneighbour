## Findings
1. **Low** `src/components/admin/ChefReviewView.tsx:80-98` (timer effect). If the automatic link refresh fails (network blip), `fetchedAt` does not change, so the timer is not set again and nothing tells the admin. The 300 s links then die silently: the images break and the "Open" links fail until the admin clicks "Reload application and file links" or refocuses the tab. Suggest: on a failed refresh, retry once after about 30 s or show a notice. Not tested in the browser (mock cannot fail a single call).

### New finding
7. **Low** `ChefReviewView.tsx` (the `auto` function in the refresh effect): `reload()` also returns false when a newer request replaced it (`mine !== seq.current`), for example when the admin clicks "Reload application" or finishes a decision while an automatic refresh is in flight.
