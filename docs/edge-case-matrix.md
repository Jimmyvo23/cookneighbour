## Findings outside the 14 rows (questions for Jimmy, see the handoff)

- **Q-T51-1.** The pre-acceptance contact filter (D-34, used by chat and the decline reason) does not see a phone number written with full-width digits (for example the full-width form of 4165550101). D-34 says "best-effort", so this is not called a bug. Should full-width digits be folded first? Not tested, so no test pins the bypass.
- **Q-T51-2.** The address key (A-2) does not fold accents or invisible characters. "Rue Édouard" and "Rue Edouard", or a street name with a zero-width space, give different keys, so the same home can get a second free trial. A-2 does not say the key must fold them. Related: "5-100 Fictional St" and "100 Fictional St Unit 5" are different keys. (CLAUDE.md 6.6 asks for the README to list the free-trial known limits, and the README does not mention them yet.)
- **Q-T51-3.** A late chef cancellation (inside 48 hours) is recorded as "late" and nothing else happens (D-20: nothing is charged). Is that the rule for chefs too, or should a late chef cancel have a consequence (for example help to find another chef, or a mark on the chef)? Row 2 tests only what is decided.
